Install help
  • Windows installers: Windows may say “Windows protected your PC.” Click More info → Run anyway. These programs aren't code-signed, so Windows doesn't recognize them yet.
  • Android apps (.apk): Open the downloaded file on your phone. If Android blocks it, allow your browser to “install unknown apps” when it asks, then tap Install.
  • VST3 plugins: Copy the .vst3 into C:\Program Files\Common Files\VST3, then rescan plugins in your DAW.
  • .zip downloads: Right-click → Extract All, then run the .exe inside the extracted folder.

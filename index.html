    Install help
    • Windows installers: Windows may say “Windows protected your PC.” Click More info → Run anyway. These programs aren't code-signed, so Windows doesn't recognize them yet.
    • Mac apps: Unzip and double-click the app. The first time, macOS says it can't be verified: click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway. After that it opens normally. If the Mac says the app is damaged and only offers Move to Trash, open Terminal, type xattr -cr and a space, drag the app onto the Terminal window, press Return, then open it again.
    • Android apps (.apk): Open the downloaded file on your phone. If Android blocks it, allow your browser to “install unknown apps” when it asks, then tap Install.
    • VST3 plugins: Unzip, then copy the .vst3 from the 64-bit folder into C:\Program Files\Common Files\VST3, then rescan plugins in your DAW. (Only a 32-bit DAW needs the 32-bit one, in C:\Program Files (x86)\Common Files\VST3.)
    • .zip downloads: Right-click → Extract All. For an app, run the .exe inside the extracted folder (pick the 64-bit one if there are two). Plugins, skills and script packs have their own steps above or on their card.
    • .7z downloads: Windows 11: right-click → Extract All. Windows 10: install the free 7-Zip, then right-click → 7-Zip → Extract.
